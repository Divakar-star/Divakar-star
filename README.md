## 🧭 What I care about when building AI systems

- **Grounded answers:** cite sources, and refuse when there's no evidence
- **Guardrails first:** injection detection, PII masking, policy checks
- **Deterministic where possible:** use the LLM for reasoning and plain code for everything else
- **Observable:** every request is traced, costed and scored
