### About me

I'm an AI engineer in Hartford, CT. I've spent the last several years building GenAI, agentic and conversational AI systems that run in production, first for American Express (through TCS) and now in healthcare at CVS Health.

Most of my work is multi-agent workflows in LangGraph, LangChain and MCP, with tool calling and a human reviewing anything risky. I build RAG pipelines with hybrid search (BM25 plus vectors), reranking and semantic chunking on Pinecone, pgvector and OpenSearch. I fine-tune open models with LoRA and QLoRA, serve them on vLLM, and don't ship a release until it passes RAGAS and LangSmith evals, guardrails and hallucination checks.

I've also built contact-center AI on Dialogflow CX, Agent Assist and CCAI Insights. I deploy on AWS and GCP with Docker, Kubernetes and Terraform, under HIPAA and PCI DSS rules. Day to day I write code with Claude Code and Google Antigravity.

MS in Computer Science, Rivier University. B.Tech, JNTUK.
